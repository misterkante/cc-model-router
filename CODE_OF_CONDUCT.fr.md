# Code de conduite

[English](CODE_OF_CONDUCT.md) · [Français](CODE_OF_CONDUCT.fr.md)

## Notre engagement

Nous voulons que ce projet soit un endroit utile et sans drame. Les contributeurs
et mainteneurs s’engagent à rendre la participation exempte de harcèlement pour
tout le monde, sans distinction d’âge, de taille, de handicap visible ou
invisible, d’ethnie, de caractéristiques sexuelles, d’identité et d’expression de
genre, de niveau d’expérience, d’éducation, de statut socio-économique, de
nationalité, d’apparence, de race, de religion ou d’orientation sexuelle.

## Comportement attendu

- Être direct sur le code et les preuves ; rester respectueux envers les personnes.
- Partir de bonne foi, mais demander des preuves quand une affirmation est mesurable.
- Garder la critique sur le travail, pas sur la personne.
- Respecter la vie privée : ne pas publier de secrets, chemins privés ou données
  d’autrui.
- Accepter qu’un mainteneur refuse un changement pour le périmètre, le coût de
  maintenance ou le manque de preuves.

## Comportements inacceptables

Le harcèlement, les propos discriminatoires, les attaques personnelles, le
doxxing, les avances sexuelles non désirées et la publication d’informations
privées sans autorisation ne sont pas acceptables. La perturbation répétée des
discussions ou des revues ne l’est pas non plus.

## Périmètre

Ce code s’applique dans les discussions du dépôt, les issues, les pull requests,
les revues et les autres espaces du projet, ainsi que lorsqu’une personne
représente le projet en public.

## Application

Signale les incidents en privé au mainteneur via GitHub. Si le signalement
concerne le mainteneur, utilise le flux de signalement d’abus de GitHub. Les
signalements seront examinés dès que possible et traités avec discrétion. Les
mainteneurs peuvent supprimer des commentaires, fermer des fils, refuser des
contributions ou bannir temporairement ou définitivement des participants.
